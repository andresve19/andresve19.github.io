# Guía de uso

## 1. Evaluación global del tiroides

En el primer panel indica el **tamaño** y la **ecoestructura** del tiroides.

- Si el estudio **no muestra ningún nódulo**, marca la casilla **"Tiroides sin nódulos"**. Esto oculta el panel de nódulos y genera directamente un informe simplificado.
- Si hay nódulos, indica cuántos nódulos ≥1 cm se estiman en total, y si procede, cuántos nódulos espongiformes (TR1) o mixtos (TR2) existen que **no** vas a describir de forma individual.

## 2. Añadir y configurar nódulos

- Pulsa **"+ Añadir nódulo"** para crear una nueva pestaña (máximo 4).
- Cada pestaña muestra un punto de color y la categoría TR calculada en vivo, para identificar de un vistazo el nódulo más relevante.
- Dentro de cada nódulo, completa por selección (point-and-click):
  1. **Lado y tercio**
  2. **Tamaño**: diámetro máximo (D1) y las otras dos dimensiones
  3. **Composición, ecogenicidad, forma, márgenes y focos ecogénicos** — cada opción muestra su puntuación ACR TI-RADS
  4. **Comparación con estudios previos**: estable, nuevo, aumentado, disminuido o sin estudio previo disponible, con un campo opcional para anotar fecha o tamaño previo
- El **banner de puntuación**, encima del formulario, muestra en tiempo real la puntuación total, la categoría TR y la recomendación de PAAF/seguimiento.
- Para quitar un nódulo, usa **"Eliminar este nódulo del informe"** (se mantiene siempre al menos uno).

## 3. Revisar y copiar el informe

- El panel derecho muestra:
  - Un **resumen rápido** con todos los nódulos y su categoría TR
  - La **vista previa completa del informe**: técnica, hallazgos e impresión diagnóstica con la recomendación global
- Pulsa **"Copiar informe al portapapeles"** y pega el texto directamente en el RIS.
- **Revisa siempre el texto antes de insertarlo** en la historia clínica: la herramienta calcula la categoría y la recomendación, pero el radiólogo es quien valida el contenido final.

## 4. Empezar un informe nuevo

El botón **"↺ Nuevo informe"**, en la cabecera, borra todos los datos introducidos (previa confirmación) y deja la aplicación lista para un nuevo estudio.
